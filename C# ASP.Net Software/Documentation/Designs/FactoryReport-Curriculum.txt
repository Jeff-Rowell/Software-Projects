1.	Introduction

This document is divided into three sections: View Models, Repositories, and
DbObjects. The Curriculum Model Factory is the basis for both the list of View
Models and the list of Repositories. The list of DbObjects is based upon the
methods included in the Repositories section. Further information regarding
notation and organization can be found in each respective section.

================================================================================

2. 	View Models

All view models have three sections of information. The first two sections list
the properties of the view model, with the “pass-through” properties being
listed first and the properties involving logic within the view model being
listed second. Any logic relevant to the non-pass-through variables is included
in the section underneath each listing. Finally, the third section contains
all logic not directly related to the properties listed in the second section.

•	public bool IsThisOrChildrenNew {
        get {
            bool isNew = false;
            if (this.IsNew) {
                isNew = true;
            }
            else if (this.ThreadParentId <= 0) { //Which means this is a parent
                foreach (var x in this.ThreadChildren) {
                    if (x.IsNew) {
                           isNew = true;
                    }
                }
            }
            return isNew;
        }
    }
•	public bool IsThisOrChildrenLive {
        get {
            bool isLive = false;
            if (!this.IsStored && !this.IsArchived) {
                isLive = true;
            }
            else if (this.ThreadParentId <= 0) { //Which means this is a parent
                foreach (var x in this.ThreadChildren) {
                    if (!x.IsStored && ! x.IsArchived) {
                           isLive = true;
                       }
                   }
               }
            return isLive;
        }
    }
