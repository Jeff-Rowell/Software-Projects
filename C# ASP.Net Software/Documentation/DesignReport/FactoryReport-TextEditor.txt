2. Repos
     a. List all repos being called by the factory
         _lessonRepo
         _narrativeRepo: _lessonNarrativeRepo
         _lessonPlanRepo: _lessonPlanLessonRepo, _context.LessonPlanLessons (MasterTeacherContext)
	 _messageUseRepo
         _messageRepo
         _lessonUseRepo
 
     b. List the repo methods being called directly.
	_lessonRepo:
		GetById > Base Class Method in BaseRepo  (returns a Lesson object)
	_narrativeRepo:
		GetById > Base Class Method in BaseRepo  (returns a Narrative object) 
		CreateNarrative > creates a Narrative object and a LessonNarrative object and inserts them in the database (returns a Narrative Object).
	_lessonPlanRepo:
		GetById > Base Class Method in BaseRepo  (returns a LessonPlan object)
		GetLessonPlanForLesson > returns a preferred LessonPlan, if available, but if it's not available then it
					 returns the preferred LessonPlan for the master lesson.
	_messageUseRepo:
		GetById > Base Class Method in BaseRepo  (returns a MessageUse object).
	_messageRepo:
		GetById > Base Class Method in BaseRepo  (returns a Message object).
	_lessonUseRepo:
		GetById > Base Class Method in BaseRepo  (returns a LessonUse object).

     c. If any of these methods are not simple queries, but can be traced back to simple queries, briefly describe this.
	 GetById is a simple query from the BaseRepo class and returns _dbSet.Find(id).
	 CreateNarrative creates a Narrative object and inserts it in the database. It has a repo call 
			 for _lessonNarrativeRepo.CreateLessonNarrative which creates a lessonNarrative
			 object and inserts it in the database.   
	GetLessonPlanForLesson() is more complex
			It first calls GetPreferredLessonPlan which contains a repo call for 
			_lessonPlanLessonRepo.GetPreferredLPLForLesson. That repo call is a simple query
			and returns the first or default LessonPlanLesson object. If the LessonPlanLesson
			object exists, then GetPreferredLessonPlan returns a LessonPlan object from the 
			LessonPlanLesson object. If the preferred LessonPlan exists, GetLessonPlanForLesson
			returns it. Otherwise, it will call GetPreferredLessonPlan again for the master lesson.
			May refactor to move some of this logic into the LessonPlan Domain Object.
